The admin needs three values in .env, and refuses to run without them. That is deliberate — an admin panel with a default password is worse than one that does not work.

Generate the credentials

Run this, then paste the three lines it prints into .env: 

.venv\Scripts\python.exe make_admin.py

It asks for a username and password, hashes the password, and prints ADMIN_USER, ADMIN_PASSWORD_HASH and SECRET_KEY. The password itself is never stored — only a hash of it, so the file cannot give it back if someone reads it.

Restart python app.py afterwards; the values are read at startup.
