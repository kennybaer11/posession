# Bookmaker possession lines. Two formats are accepted.
#
#   python import_odds.py odds.txt --dry-run     check the matching
#   python import_odds.py odds.txt               load them
#
# FORMAT 1 - paste straight from chance.cz. Tab-separated, the site's own
# column order, Czech decimal commas and wording all handled:
#
#   Day  Match  Bet  Under  Under-odd  Over  Over-odd
#
# Copy the row out of the table and paste it. The club the line is about is
# read from the Bet column, not the Match column - those are not always the
# same club, and the Bet column is the one that says what you are betting on.
#
# FORMAT 2 - compact, if you are typing by hand:
#
#   date        club   club   whose-possession   line   O<over>  U<under>
#   2026-09-06  ARS    CHE    ARS                54.5   O1.75    U1.94
#
# TAG THE PRICES with O and U, and their order stops mattering. chance.cz lists
# UNDER first while an untagged pair here is read as OVER first, so an untagged
# row is one transposition away from recording the opposite bet - and a swap
# does not fail, it silently reverses which side the model backs.
#
# There is no reliable way to detect such a swap afterwards: whether OVER is
# the longer price depends on where the line sits relative to that team's usual
# possession, not on the line itself. Tagging removes the ambiguity instead.
#
# Club order does not matter; the fixture is found from the pair. Use
# abbreviations (ARS, MCI, NFO) or names without spaces. Put "-" for a price
# you do not have.
#
# BOTH PRICES ARE WORTH THE EXTRA COLUMN. They reveal the bookmaker's margin:
# the two implied probabilities sum to more than 1, and the excess is the tax
# you pay. On the first two-sided lines recorded here it came out at 8.7%,
# which is high - a match-result market is usually 3-5%. With only one price
# that number is invisible, and every edge looks better than it is.
#
# Settled matches are worth more than upcoming ones: they are what turns the
# Bets page from a diary into evidence.
