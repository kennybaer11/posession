# Bookmaker possession lines, entered by hand.
#
#   python import_odds.py odds.txt --dry-run     check the matching
#   python import_odds.py odds.txt               load them
#   python import_odds.py odds.txt --closing     mark as closing lines
#
# Columns, whitespace-separated:
#
#   date         the match date, YYYY-MM-DD
#   home         home club
#   away         away club
#   team         whose possession the line is about (usually the home side)
#   line         the over/under number, e.g. 54.5
#   over         decimal odds for OVER   ("-" if you don't have it)
#   under        decimal odds for UNDER  ("-" if you don't have it)
#
# Club names: write them however the bookmaker does. The importer matches
# against full name, short name and abbreviation, then falls back to a fuzzy
# match, so Arsenal / Brighton / Spurs / MUN all resolve. Avoid spaces inside
# a name - "Man City" would be read as two columns; write ManCity or MCI.
#
# BOTH prices are wanted wherever you can get them. The two implied
# probabilities sum to more than 1, and that excess is the bookmaker's margin.
# Without the other side it cannot be stripped out, and the model gets compared
# against a margin-inflated probability - which flatters it, in the direction
# that costs you money.
#
# Older settled matches are worth far more than upcoming ones: those are what
# make it possible to ask whether backing the model's edges would actually have
# won. Twenty or thirty past lines would settle the question.
